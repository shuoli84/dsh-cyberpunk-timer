# dsh-plugin-cyberpunk-clock

一个可拖动的赛博朋克风格 24 小时制数字时钟，挂在 DeepSeek Harness Web 页面右上角，并支持本地、可编辑的「时间点提醒」。

## 安装

```sh
dsh plugin --profile web add ~/dsh-plugins/dsh-plugin-cyberpunk-clock
```

安装后重启 `dsh web` 即可生效。

## 移除

```sh
dsh plugin --profile web remove dsh-plugin-cyberpunk-clock
```

## 功能

### 时钟
- 24 小时制 `HH:MM:SS` 数字时钟，每秒刷新
- 本地日期显示
- 鼠标/触控直接拖动，位置被限制在可视区域内（不会拖出屏幕消失）
- 赛博朋克霓虹视觉：青色/洋红发光、扫描线、闪烁冒号

### 时间点提醒
- 可保存多个带名称的时间点（如「饭点 12:00」「下班 18:00」），每日循环
- 存储于浏览器 `localStorage`（键 `dsh.cyberpunk-clock.state.v1`），刷新页面 / 重启 Web 后仍在
- 进入「提前窗口」后（默认提前 10 分钟，可调），大时间与命中的条目会有低频率呼吸闪烁
- 临近时在整个 DSH 页面顶部显示全宽走马灯，循环滚动所有命中提醒；越过时间点自动消失且不阻挡任何点击
- 日期行右侧的 `▣N` 入口随时管理：新增、编辑、删除时间点，并调整提前量（5～240 分钟）

## 使用

1. 点击时钟右下角日期行右侧的 `＋` / `▣N` 展开提醒抽屉。
2. `+ 新增` 输入名称与时间（`HH:MM`）保存。
3. 底部 `提前 [n] 分钟 − ＋` 调整提前量。
4. 无需提醒时把条目全部删除即可，面板回到纯时钟状态。
